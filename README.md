### Backend Developer — *IdeyaLabs*, Hyderabad | `June 2025 – Present`

**Project: APEX — Transportation Back Office System**

- Developed production-grade **REST APIs** using **FastAPI, Pydantic, SQLAlchemy, and multi-schema PostgreSQL**, following a domain-driven module architecture.
- Built client workflows for **account lookup, shipment creation/listing/export, pickup scheduling and rescheduling, quick quotes, freight rating, density calculations, ZIP lookup, and shipping instruction codes**.
- Implemented **Pricing & Rating** capabilities for **fuel prices and surcharge scales, accessorial charges/schedules, rate bases, lane minimums, high-cost ZIPs, pricing rules, and global/volume rates**.
- Developed domain modules for **Client Management, Customer Profiles, Billing, Claims, and Transit Times**.
- Integrated **SMC3 freight rating, HERE/Google geocoding, EIA fuel pricing, Daylight services, Falvey insurance, NMFTA, and Shiplify**, alongside AWS services.
- Built document workflows for **bills of lading, shipping labels, blind shipment forms, billing/claims uploads, email notifications, and Excel/CSV exports**, using **AWS S3 and SES**.
- Implemented **role-based access control (RBAC)** for backend APIs with **AWS Cognito-issued JWTs**, plus typed responses, centralized exception handling, and structured JSON logging.
- Deployed the application on **AWS Lambda** with **Mangum and AWS CDK**; used **GitHub Actions** for CI/CD and **Pytest, Ruff, and Mypy**, maintaining **80%+ test coverage**.

`Python` `FastAPI` `PostgreSQL` `SQLAlchemy` `Pydantic` `AWS Lambda` `AWS CDK` `Cognito` `RBAC` `GitHub Actions`
